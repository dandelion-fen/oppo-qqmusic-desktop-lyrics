# 使用教程

## 一、第一次连接：建议先用 USB

1. 完整解压 Release 中的 Windows ZIP，运行 `QQPhoneLyrics.exe`。下载源码的用户先参照 README 准备 Python 和 ADB。
2. 开启 OPPO 的开发者选项和 USB 调试，使用数据线连接电脑。
3. 解锁手机，在「允许 USB 调试」弹窗中允许电脑。如果是自己的电脑，可选择始终允许。
4. 打开 QQ 音乐，开启通知栏歌词并播放歌曲。
5. 在控制台勾选「直接显示手机通知歌词」。连接状态应显示已连接，歌词区域显示当前句。
6. 没有手机时可以先用「预览效果」检查外观，再点一次返回同步模式。

直接通知歌词模式不要求电脑联网。QQ 音乐手机端仍按其正常播放方式联网或播放缓存。

## 二、设置成透明桌面歌词

1. 勾选「背景完全透明」。背景会消失，只留下歌词和辅助信息。
2. 点击「歌词颜色」，选择喜欢的文字颜色；「下一句颜色」也控制直接模式下歌名 / 歌手信息的颜色。
3. 使用「整体透明度」控制文字的可见程度。值越低越透明。
4. 根据需要开启「歌词始终置顶」。

透明背景与文字透明度不同：背景完全透明时仍可保留清晰文字。
调整模式会暂时提高整体可见度，完成调整后恢复滑块设置。

## 三、移动、缩放及鼠标穿透

1. 点击控制台「调整位置和大小」。
2. 拖动歌词左上角「✥ 拖动」移动整个歌词窗口；也可拖动不透明的歌词文字。
3. 拖动右下角「↘」调整窗口宽高。拉宽可以减少长歌词换行。
4. 用字号滑块或 Ctrl + 鼠标滚轮调整文字大小。窗口尺寸变化不会自动修改字号。
5. 点击「完成调整」，两个操作手柄隐藏。没有原生系统标题栏，也没有不透明顶部条。
6. 如不希望影响下面的软件，勾选「鼠标穿透」。
7. 需要重新调整时，按 Ctrl + Alt + L，或回到控制台点击调整按钮。若快捷键已被其他软件占用，请使用控制台按钮。

位置、宽高和样式自动保存。关闭控制台会退出整个程序。窗口跑到找不到的位置时点击「恢复歌词位置」。

## 四、无线连接

需要 Android 11+，并在开发者选项提供「无线调试」。手机与电脑连接同一 Wi-Fi，网络不能开启客户端隔离。

1. 手机上打开「无线调试 → 使用配对码配对设备」。
2. 电脑点「无线连接」，填写**配对页面**显示的 IP:端口和配对码，点「配对」。
3. 返回手机无线调试主页，找到主页显示的 IP:端口。
4. 将电脑输入框改成**主页的连接地址**，点击「连接」。配对时使用的端口通常不是连接端口。
5. 无线连接成功后可拔掉 USB。

手机重连 Wi-Fi 后 IP 或端口可能变化，需要重新连接。配对信息通常可保留，但也可能被系统撤销。
系统关闭无线调试、Wi-Fi 隔离或防火墙规则都可能使连接中断。不要为了连接而关闭整个防火墙；可先使用 USB 排除网络问题。

## 五、备用：按歌名匹配或加载 LRC

如果手机没有发布通知歌词，但提供了真实歌名和播放进度，可以取消「直接显示手机通知歌词」。
程序优先查询 QQ 音乐，失败后尝试网易云。匹配结果显示在控制台。

如果控制台正在把一整句歌词当作歌名查询，请切回直接通知歌词模式；或者先关闭手机通知栏歌词，让 QQ 音乐重新发布真实歌名。

自动匹配不正确时：

1. 确保 LRC 对应当前歌曲的同一个版本，点击「加载本地 LRC」。
2. 文件需包含 `[00:12.34]歌词` 这样的时间标签，支持 UTF-8 / GB18030。
3. 使用「同步偏移」微调：正值让歌词提前，负值让歌词延后。
4. 手机切歌后会重新匹配，手动 LRC 仅针对当前歌曲。

时间偏移、本地 LRC 和联网匹配均用于备用模式，不会改变直接通知歌词模式的手机原始歌词时间。

## 六、常见问题

| 现象 | 排查方法 |
|---|---|
| 等待手机，Windows 只识别到设备名称 | 开启 USB 调试；手机解锁后拔插线，确认允许授权；必要时选择文件传输模式或换数据线 |
| 没出现授权弹窗 | 在开发者选项撤销 USB 调试授权，再拔插 USB 重新允许 |
| 手机反复离线 | 先换线 / USB 口，避免 USB 集线器；检查驱动与授权状态 |
| 找不到 ADB | 点击「选择 adb.exe」，选择官方 Platform-Tools 中的文件 |
| 显示的是歌名而不是歌词 | 开启 QQ 音乐通知栏歌词，并勾选电脑的直接通知歌词模式；若版本不发布歌词，使用备用匹配模式 |
| 之前能同步，现在一直停在同一行 | 先确认手机连接；若这一行实际是歌名，说明手机当前只发布歌名和进度。取消「直接显示手机通知歌词」，使用电脑匹配歌词；重新打开通知栏歌词不一定立即恢复逐句发布 |
| 一直搜索却匹配失败 | 检查是否正在将通知歌词句当成歌名；有通知歌词时应使用直接模式 |
| 拖不动歌词 | 使用调整按钮或 Ctrl+Alt+L 进入编辑模式，再抓住左上角文字手柄；透明空白区域会将点击传给下方窗口 |
| 字太小 / 长句换行 | 单独调整字号、窗口宽度；不要只拉大窗口期待字体自动变大 |
| 不能逐字高亮 | 当前只支持逐句；直接模式受手机媒体信息的更新频率限制 |
| 锁屏后不更新 | 检查 QQ 音乐的后台运行限制；无线连接还需检查无线调试是否被系统关闭 |
| 关闭开发者选项后不同步 | 本工具依赖 ADB；USB 连接必须保留 USB 调试，无线连接必须保留无线调试 |
| 设置想全部重置 | 退出程序，备份并删除 `%LOCALAPPDATA%\QQPhoneLyrics\settings.json`，重新运行 |

## 七、平常能否开启开发者模式

可以保持开发者选项开启，并正常退出设置页面，不必一直停留在开发者设置中。
仅开启开发者选项和 USB 调试通常不会明显增加耗电；歌词程序持续读取媒体信息及无线连接本身仍会产生一定开销。

- 使用 USB 同步时，保留 USB 调试；关闭它或关闭整个开发者模式会断开同步。
- 使用无线同步时，保留无线调试；无线调试不用时可关闭，USB 同步不需要它。
- 只允许可信的个人电脑调试，不允许陌生电脑的授权请求。
- 不熟悉的其他开发者设置保持默认即可。
- 长期不使用本工具时，可以关闭调试或撤销已授权电脑；再次使用需要重新连接、授权。

## 八、诊断与反馈

在 Platform-Tools 目录打开 PowerShell：

```powershell
.\adb.exe devices -l
.\adb.exe shell dumpsys media_session
```

多台设备时，使用 `adb.exe -s 目标序列号 shell dumpsys media_session` 指定目标。
检查 QQ 音乐对应段落的 `package=com.tencent.qqmusic`、`state` 和 `metadata`。

反馈时说明系统版本、QQ 音乐版本、连接方式、是否开启通知栏歌词，以及暂停 / 恢复 / 切歌 / 锁屏时的表现。
分享输出前去掉设备序列号、其他应用信息和个人内容。不要提交 ADB 私钥、登录令牌或本地个人设置。
